# Security policy

## Supported versions

Only the latest version on the `main` branch is supported with security fixes. The site deploys from `main`; older commits and branches do not receive backported fixes.

## Reporting a vulnerability

Please report suspected security vulnerabilities privately through [GitHub's private vulnerability reporting for this repository](https://github.com/rockfeverLLN/rockfever/security/advisories/new). Do not open a public issue or include exploit details in a public discussion.

Include, where possible, the affected page or component, the impact, steps to reproduce, and any proof of concept that can be shared safely. A report without a working proof of concept is still welcome.

The maintainers will acknowledge reports as soon as practical, investigate them, and coordinate any fix and disclosure with the reporter. Please allow time for a fix before sharing vulnerability details publicly. We cannot promise a particular response or resolution time.

If GitHub's private reporting form is unavailable, contact the Rock Fever team through the [site contact page](https://rockfever.be/contact) and ask for a private security-reporting channel. Do not send sensitive exploit details through the public contact form.
